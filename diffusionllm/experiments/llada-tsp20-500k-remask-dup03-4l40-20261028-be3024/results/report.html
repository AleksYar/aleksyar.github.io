IMPORTANT LIMITATION · BOTH TRAINED MASKING HEADS

TSP-only head and decoder: cannot answer general questions

This applies to the head trained in the 500k experiment and its additional 300k continuation. Both require city coordinates and route positions. The tested decoder supplies a fixed tour format and restricts predictions to city IDs. These heads do not provide general-purpose token remasking.

Underlying LLaDA + LoRA: the same weights can be run with ordinary text decoding, with the TSP head bypassed. That is a different generation procedure. These experiments did not evaluate general-question quality through ordinary decoding.

The reported TSP scores include this specialized decoder; they are not evidence of general-purpose chat with the head active.

All 100 final tours were valid. Remasking repaired six invalid tours and shortened eleven others, increasing optimal answers from 44 to 51.

How inference works

  1. Construct an initial route in 16 diffusion passes, using fixed two-digit city fields.
  2. The prediction head scores candidate groups of city positions. For a valid route it predicts achievable gain; for an invalid route it predicts repair feasibility.
  3. The decoding program masks the selected positions, then LLaDA fills them again. The head chooses the edit; it does not emit MASK tokens as ordinary answer text.
  4. Accept a candidate only if it creates a valid tour from an invalid one, or improves the best valid tour. Otherwise retain the incumbent. Stop at the threshold or the 128-call budget, including selector calls.

Valid routes offer 258 pair or contiguous-segment actions; invalid routes also offer 19 singleton actions. The gain threshold is 0.05. Some cases accepted multiple revisions. Final validity belongs to this complete selection, refill, and acceptance process.

Each training record uses a fresh geometry: 20 distinct integer-coordinate points in [0, 999]. Optimal references use HiGHS MILP with subtour cuts. Correction targets use exact conditional repair while preserving unmasked positions; the head learns gain and feasibility for assessed mask groups.

The head’s gain target is what the conditional solver can achieve, rather than the improvement a particular LLaDA refill is guaranteed to achieve. Clean examples use dynamic masking; correction examples use labelled masked city positions.

Prediction head and loss details

City representations are pooled from the two digit-token states and projected from 4,096 to 256 dimensions. Candidate action features feed a 128-unit hidden layer with two outputs: predicted gain and repair feasibility. Head dropout is 0.1.

Selector loss combines Huber gain regression, feasibility binary cross-entropy, and a 0.1-weight pairwise ranking term. Only assessed actions contribute labels. The duplicate penalty excludes the final repeated city 0 used to close the cycle.

Independent audit passed

Every initial and final objective was recomputed from the original coordinates using unrounded Euclidean distances, including the closing edge back to city 0. The maximum discrepancy from the saved objectives was 0.

All 1,226 revision proposals, acceptance decisions, unmasked positions, reference-route lengths, and forward-call counts were checked. A valid tour visits each city exactly once before the closing zero. Invalid routes receive no objective or gap score.

The objective is calculated by code from the generated route. This run does not establish that LLaDA learned to generate accurate numerical objective text. Existing numerical optimality certificates were retained; the reference optimization was not rerun for the audit.

Limits of this result

  • This is one evaluation on the historical 100-case benchmark. It does not establish a general 100% validity guarantee.
  • There was no random-mask, confidence-mask, or equal-budget no-head comparison. Gains cannot all be attributed to the prediction head alone.
  • General-question performance with the trained adapter enabled was not evaluated.
