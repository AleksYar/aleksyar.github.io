Two independent LoRA experiments

Training scripts implemented. See the results page for the current run status.

Each problem has its own 10,000 training examples, 100 validation cases, adapter, and one-A40 job. Both adapters start from the same untuned LLaDA-8B-Instruct checkpoint.

Execution sequence

  1. Evaluate the untuned model on the 100 validation cases using the new prompt.
  2. Train for one epoch: 625 updates, LoRA rank 16 / alpha 32, learning rate 1e-4, effective batch size 16.
  3. Save checkpoints every 125 updates; inspect the same 20 validation cases after updates 125 and 375.
  4. Evaluate the final adapter on all 100 cases with the same 512 output positions and 128 diffusion steps.
  5. Produce one before/after table for each problem, retaining every answer and its exact reference.

The new prompt includes two nearest-neighbor hints and asks for both a route and its distance. Fresh untuned baselines are needed because earlier TSP5/TSP10 tests used a different prompt.

What the result should show

Report complete and optimal tours out of 100, strict format compliance, distance gap on complete tours, reported-distance accuracy, and whether responses use the coordinates instead of repeating a fixed route. Compare against exact solutions and CPU heuristics. The model's claimed distance is not used to score its route.

Data checks

All 20,200 examples fit the 1,024-token limit without truncation. Training and validation have no duplicate geometry. Labels come from an exact solver. City labels are randomized and equivalent tour reversals are handled consistently.
