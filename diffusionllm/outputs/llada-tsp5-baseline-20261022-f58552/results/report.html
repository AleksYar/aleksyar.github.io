Run details

Untuned GSAI-ML/LLaDA-8B-Instruct, BF16, no quantization or adapter; temperature 0, seed 42. The prompt gives coordinates only and requests one route without an explanation. Model revision and the unchanged official sampler are pinned in the provenance below. Job 1458378 completed on newton4, one NVIDIA A40, within a 15-minute limit.

Average generation: 12.50 seconds per instance. Peak allocated GPU memory: 15.25 GiB. Job time includes startup and scoring; queue time is separate. All 20 exact optima were also checked by enumerating all tours locally.

This is a new TSP5 development dataset, not a paired comparison on the same TSP10 instances. The change in problem size is deliberate; no prompt wording was tuned after observing answers.
