IMPORTANT LIMITATION · BOTH TRAINED MASKING HEADS

TSP-only head and decoder: cannot answer general questions

This applies to the head trained in the 500k experiment and its additional 300k continuation. Both require city coordinates and route positions. The tested decoder supplies a fixed tour format and restricts predictions to city IDs. These heads do not provide general-purpose token remasking.

Underlying LLaDA + LoRA: the same weights can be run with ordinary text decoding, with the TSP head bypassed. That is a different generation procedure. These experiments did not evaluate general-question quality through ordinary decoding.

The reported TSP scores include this specialized decoder; they are not evidence of general-purpose chat with the head active.

Generate, mask, reconstruct, and keep the latest result. This test allows worse and invalid routes to become the next input, for up to 256 total model calls.

What ran

  1. The trained model generated the initial route in 9 useful diffusion passes.
  2. One backbone/head pass selected a pair or segment to mask; invalid routes also allowed single-city masks.
  3. Both digit tokens of each selected city were replaced with the actual mask token.
  4. The model reconstructed the selected fields in up to 16 useful passes, at most 8 for the available repair masks, or 1 for an invalid-tour singleton.
  5. Every completion became the next input. The loop continued until fewer than two calls remained.

The 256-call cap includes selection and reconstruction. The stop/KEEP threshold was disabled. City 00 and the route format remained fixed; uniqueness was not enforced. Validity remains an existing head feature, but objective values and reference optima never control the trajectory.

This is a fixed-budget stress test of the trained selector and reconstruction model. The head can repeatedly choose the same mask on an unchanged route. It can also disturb an optimal route because this test forces continued masking.

3,062 remasking cycles; 44,074 digit-token mask operations. 2,961 selections repeated the preceding action on the same input, across 100 cases.

91 cases never changed their route. The mean number of distinct complete routes visited was 1.10.

What this measures

This is transfer to 10-city problems from a checkpoint trained on TSP20. Every adapter and head weight is unchanged. The code generalizes city choices, neighbor indexing and candidate masks to 10 cities; relative-position features use N−1. The same change reproduced the original TSP20 head outputs exactly in a local regression check.

The dataset contains 100 new geometries with certified reference solutions. No geometry was reused from the available earlier same-size data. The results describe this fixed decoding procedure on these 100 cases; there is one seed per case and no tuning on these results.

Mask candidates remain pairs and segments of at most 8 cities, even for TSP40. The final score includes all worse and invalid completions; route lengths and reference optima are used only after inference. The compute estimate covers both requested sizes, 200 cases total.
