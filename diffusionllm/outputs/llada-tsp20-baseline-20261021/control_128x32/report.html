How to interpret this first test

This is a baseline for deciding what TSP fine-tuning must improve. Success in the next experiment means more valid tours and a higher valid-and-within-5% rate on a separate held-out set, under the same inference budget.

A valid tour contains every city exactly once before explicitly returning to its starting city. Rotations and reverse directions are accepted. No missing city, duplicate, open route, or unparseable answer is repaired. A unique unlabelled bracketed list can be accepted semantically; exact requested output formatting occurred in 0/5 answers.

Gap = 100 × (model tour length / optimal tour length − 1). Lengths use unrounded Euclidean distances. Every reference was solved by degree-2 mixed-integer optimization with subtour elimination, a connected solution, HiGHS status 0, and relative tolerance 10−9. This is a numerical optimality certificate.
