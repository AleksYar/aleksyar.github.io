How to interpret this test

Both runs use one full output block, temperature 0, seed 42, BF16, no quantization, no TSP training, and one response per instance. The new run doubles both output positions and steps; block length increases from 128 to 256 to keep one block. Both commit two positions per pass. This is a joint change, so any difference cannot be attributed to step count alone.

Primary scoring requires one parseable bracketed list containing a closed tour with every city exactly once before returning to the start. Exact prompt-format compliance is shown separately. Invalid tours have no optimality gap. No answers were repaired, retried, or selected from multiple candidates. These reused 20 development instances do not constitute an independent final evaluation.
